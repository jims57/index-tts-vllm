GET / - 健康检查接口
▶

接口描述

检查TTS服务是否就绪。只有当TTS模型加载完成后才返回健康状态。

成功响应 (TTS服务就绪)

{"errorCode": 0, "message": "Index-TTS-vLLM API is running"}

错误响应 (TTS服务未就绪, HTTP 503)

{"errorCode": 5003, "message": "TTS service is not ready yet, model is still loading"}
WebSocket /tts - TTS流式合成接口
▶

接口描述

WebSocket流式TTS接口，支持实时语音合成。连接后可发送多个TTS请求，支持停止正在进行的TTS生成。

连接参数

x-api-key (Header, 必需) - API密钥

JSON请求体参数

text (String, 必需) - 要合成的文本内容
speakerId (String, 可选) - 说话人ID或音频文件路径，默认: "4582b310374bcb6633f2d459bd29811c"
outputSampleRate (Integer, 可选) - 输出采样率，默认: 16000
audioFormat (String, 可选) - 音频格式 "pcm" 或 "mp3"，默认: "pcm"
startTimeId (Integer, 可选) - 开始时间ID，用于音频块头部
messageId (Integer, 可选) - 消息ID，用于音频块头部和停止控制
saveAudioFiles (Boolean, 可选) - 是否保存音频文件到服务器，默认: false
language (String, 可选) - 语言代码 "zh", "zh-cn", "en"
seed (Integer, 可选) - 随机种子，默认: 42

TTS请求示例

{"text": "今天的天气怎么样？", "speakerId": "d10bb92ab03c9e8c301a3ab2ca11fba3", "language": "zh", "audioFormat": "mp3", "outputSampleRate": 16000, "startTimeId": 1234567890, "messageId": 1}

停止TTS请求示例

{"task": "stopTTS", "messageId": 1}

响应格式

成功时返回二进制音频数据流。当提供startTimeId和messageId时，每个音频块前有12字节头部：8字节startTimeId + 4字节messageId，后续为音频数据。TTS完成时发送空音频块作为完成信号。

错误响应

4401: API密钥无效
4400: 参数无效 (text is required)
5000: TTS生成失败
5001: MP3转换失败
POST /denoiseAudio - 音频降噪接口
▶

接口描述

上传PCM音频文件进行降噪处理，为语音克隆做准备。使用RNNoise进行降噪，支持自定义输入输出采样率。

请求参数

audio (File, 必需) - PCM音频文件 (仅支持.pcm格式)
sessionId (String, 必需) - UUID会话标识符
inputSampleRate (Integer, 可选) - 输入PCM采样率，默认: 16000
outputSampleRate (Integer, 可选) - 输出WAV采样率，默认: 16000
x-api-key (Header, 必需) - API密钥

格式要求

文件格式：仅支持 .pcm 文件 | 位深：16位小端格式 | 声道：单声道

成功响应示例

{"errorCode": 0, "message": "Audio denoised successfully", "sessionId": "a1b2c3d4-e5f6-7890-1234-567890abcdef", "speakerId": "47e38dc7e8e8223b4f2c8e91a3b1d6f9"}

错误响应

4608: sessionId格式无效
4609: 文件格式不支持
4610: PCM转WAV失败
4611: ffmpeg未找到
4614: WAV文件未创建
4615: 服务器内部错误
POST /cloneVoice - 克隆语音接口
▶

接口描述

使用会话中的降噪音频文件生成语音克隆，返回speaker ID和MP3文件URL（体积更小，适合移动端下载）。服务器同时保存WAV文件用于TTS生成。

请求参数

Content-Type (Header) - application/json
x-api-key (Header, 必需) - API密钥
text (String, 必需) - 要合成的文本内容
sessionId (String, 必需) - UUID会话标识符（需先调用denoiseAudio）

成功响应示例

{"errorCode": 0, "message": "Voice cloned successfully", "speakerId": "47e38dc7e8e8223b4f2c8e91a3b1d6f9", "mp3Url": "http://your-server:9001/resource/47e38dc7e8e8223b4f2c8e91a3b1d6f9.mp3", "text": "你好"}

错误响应

4401: API密钥无效
4608: sessionId格式无效
4516: 未找到降噪音频文件
4517: 克隆失败
4518: 音频生成失败
4519: PCM合并失败
4520: WAV转换失败
4521: MP3转换失败
GET /resource/{resource_id} - 资源访问接口
▶

接口描述

获取音频文件（支持MP3和WAV格式）。

请求格式

/resource/{md5}.mp3 - 直接下载MP3文件（无需API密钥，推荐移动端使用）
/resource/{md5}.wav - 直接下载WAV文件（无需API密钥）
/resource/{md5} - 获取MP3文件URL（返回JSON）

成功响应示例

{"errorCode": 0, "message": "success", "mp3Url": "http://your-server:9001/resource/47e38dc7e8e8223b4f2c8e91a3b1d6f9.mp3"}

错误响应

4530: WAV文件未找到
4531: WAV文件MD5格式无效
4532: 资源ID格式无效
4533: MP3文件未找到
4534: MP3文件MD5格式无效
FORMAT 格式示例
▶

UUID格式示例

UUID用于sessionId，格式为32个十六进制数字用连字符分隔：

a1b2c3d4-e5f6-7890-1234-567890abcdef

MD5格式示例

MD5用于speakerId，格式为32个十六进制字符：

d10bb92ab03c9e8c301a3ab2ca11fba3
AUTH 认证信息
▶

API密钥

请在HTTP请求头中包含有效的API密钥：

x-api-key: your-api-key

认证说明

- 所有API都需要有效的API密钥（除了直接下载.mp3/.wav文件）
- WebSocket连接需要在Header中提供x-api-key
- 直接访问 /resource/{md5}.mp3 或 /resource/{md5}.wav 无需API密钥
- 如需获取API密钥，请联系Jimmy开发者
